---

Lets you build marine/recon/cataphract armor (and various modded power armors) out of **any
metal** instead of fixed plasteel, with protection scaling to the chosen material. A pure-XML
PatchOperation mod. Updated to run on RimWorld 1.6.

Full feature list, the implementation pattern, and every affected item are documented in
[DOCUMENTATION.md](DOCUMENTATION.md).
