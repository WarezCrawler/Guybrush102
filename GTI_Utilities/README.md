# GTI Utilities — Custom Patches

> ## ⚠️ FOR PERSONAL USE ONLY
> This is a **private, personal mod** created and maintained by **WarezCrawler** for use in my
> own RimWorld games. It is an original GTI creation (not a fork), and it is **not** intended
> for redistribution or public release.

---

A personal grab-bag of custom XML patches for RimWorld. Patches are parked/enabled individually
by toggling file extensions (`.xml` = active, `.xm_` = disabled).

See [DOCUMENTATION.md](DOCUMENTATION.md) for what each patch does and [CHANGELOG.txt](CHANGELOG.txt)
for the change history.
