An in-game memory/garbage cleaner for RimWorld 1.6. This fork copies the upstream C# source,
verifies every feature and reflection target against the installed vanilla assemblies, and
fixes bugs found along the way.

Maintenance, verification status, and open decisions are documented in
[FORK_NOTES.md](FORK_NOTES.md).
